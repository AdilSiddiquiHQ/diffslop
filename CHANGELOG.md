# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-29

Initial release. Catch AI agent slop, weakened tests, and ghost code in your git diff before your human reviewers have to.

### Added

- **Diff-scoped analysis (`git diff -U0`):** Targets only added lines (`+` lines) from pull requests, branches, or staged changes, ensuring fast analysis that never blocks PRs on pre-existing legacy code.
- **8 deterministic detector rules:**
  - `SLOP01_TAUTOLOGICAL_ASSERT`: Catches `expect(true).toBe(true)`, `assert(true)`, `expect(x).toBe(x)`, and hollow `expect(res).toBeDefined()` assertions that fake test coverage.
  - `SLOP02_SWALLOWED_ERROR`: Catches empty `catch {}` blocks, unhandled promise rejections `.catch(() => {})`, and swallowed exceptions.
  - `SLOP03_AI_CHAT_REMNANT`: Catches conversational AI commentary left behind (`// Note: This was updated to avoid...`, `// Generated by Claude`, `// TODO: implement real logic`).
  - `SLOP04_TYPE_ESCAPE_HATCH`: Catches `as any`, `as unknown as any`, `@ts-ignore`, `@ts-nocheck`, and unannotated linter suppressions.
  - `SLOP05_GHOST_DECLARATION`: Detects unexported functions, classes, and variables declared in diffs but never referenced in the file.
  - `SLOP06_PRODUCTION_MOCK_FALLBACK`: Catches inlined test-mode branches (`if (process.env.NODE_ENV === 'test') return ...`) and fake data returns in production logic.
  - `SLOP07_LOCAL_PATH_LEAK`: Flags hardcoded `/Users/...` machine paths, local file URLs, and exposed high-entropy credential tokens.
  - `SLOP08_COLLATERAL_DIFF_NOISE`: Detects trailing whitespace, consecutive blank line churn, and accidental formatting noise.
- **Deterministic Slop Index (%):** Transparent scoring formula calculating penalty points per added line from 0% (pristine) to 100% (heavy slop).
- **Execution speed (< 25ms):** Zero runtime dependencies and instant local scanning.
- **Zero runtime dependencies:** Built entirely with Node.js built-in modules (`node:fs`, `node:child_process`, `node:path`).
- **Composite GitHub Action:** Ready-to-use GitHub Action (`action.yml`) with strict POSIX shell runner (`scripts/diffslop.sh`).
- **Flexible CLI flags:** `--since <ref>`, `--staged` (pre-commit gate), `--all`, `--max-index <n>`, `--fail-on-slop`, and `--json`.
- **Programmatic JavaScript API:** Direct Node.js export for custom tooling (`auditGitDiff`, `auditRawDiff`, `formatReport`).
- **Reproducible demo examples:** `examples/shop-slop` (34% Slop Index with 7 issues) and `examples/shop-clean` (0% Slop Index, clean).
